HOW IT WORKS

You ship it.
We maintain it.

Sign up, connect GitHub, select the apps, and choose Starter, Indie, or Studio. That is the whole onboarding. After that, CodeCare runs the maintenance.

Connect GitHub once

Install the GitHub App and select the apps you want maintained. You do this one time.

Daily or weekly scans

Each app runs on the cadence you pick. Scans look for vulnerable and outdated dependencies, failing workflows, and code issues.

Fixes you can describe

Or skip the scanner and type the bug in plain words. CodeCare files it as a maintenance task.

Verified pull requests

A pull request opens only after the sandbox verifies the change. If verification is inconclusive, nothing is opened.

Optional auto-merge

Off by default. Turn it on per app and CodeCare merges only when verification passed and GitHub accepts the merge.

A monthly report

The workspace shows what was checked and which pull requests shipped. Email the same report when SMTP is configured.

GitHub, Stripe, AI, and SMTP stay inactive until those credentials are set. The product reports that state instead of inventing a successful run.
